# Compatibility

The offline core targets current evergreen desktop browsers with ES modules, `structuredClone`, `crypto.randomUUID`, local storage and Blob downloads. The 3D scene preview additionally needs WebGL; a browser without WebGL must show an unavailable state rather than simulate GPU rendering.

The editor has responsive layout rules for laptop/tablet widths, but the 1440 × 900 desktop reference is the primary visual target. No physical DMX hardware, Art-Net, sACN, MVR/GDTF, Figma, Adobe, ASE, Procreate, PDF, cloud collaboration or mobile-3D compatibility has been validated.
