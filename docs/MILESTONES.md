# Milestone acceptance

| Milestone | Evidence required | State |
| --- | --- | --- |
| M0 Repository audit | Corporate, division, design system and product audit with constraints recorded in M0_AUDIT.md | Verified |
| M1 Studio interface | Render at 1672 × 941 and 1440 × 900 against the reference. Verify narrow layouts, menu spacing and floating Lux controls. | Partial |
| M2 Localization and accounts | Exercise EN, DE, Yoruba and Nigerian Pidgin flows. Verify guest and signed-in states, cloud save and restore, and owner isolation. | Partial |
| M3 Palette and canvas | Verify color conversions, harmony, contrast, editing and project round-trips. | Partial |
| M4 Lighting and DMX | Verify interactive rendering, fixture import, patch conflicts and cue playback. Document hardware transport limits. | Partial |
| M5 Lux and exports | Verify proposals, approval, undo and advertised export round-trips. Identify external services and formats that require separate support. | Partial |
| M6 Release | Pass local and hosted checks, verify the merged commit and deployed assets, and complete browser acceptance against the reference. | Interim release verified |

For each completed increment, record the checks, GitHub commit and live release run before advancing. Treat integration and visual acceptance as separate from build success.
