# Internationalization

The first complete locale set is English (`en`), German (`de`), Yoruba (`yo`) and Nigerian Pidgin (`pcm`). UI strings use stable keys. Runtime switching persists only a locale preference and never changes fixture identifiers, dimensions, DMX addresses or project values.

Missing keys must show a development warning and English fallback; a locale is not marked reviewed merely because it has a label in the language menu. Specialist lighting terms may remain in English where translating them makes the engineering meaning less clear.
